# Development status

LibreQuadri supports local multi-brand catalogue import and search,
technical product and accessory configuration, enclosure configuration,
physical placement, Fronte Quadro visualization, quotations, material lists,
project persistence and PDF export.

Engineering coverage depends on the manufacturer source generation and
imported catalogue. The current export dialog supports Distinta and Fronte
Quadro. An internal quotation PDF template is implemented and tested but is
not exposed as a separate export choice.

Development continues on catalogue distribution and updates, broader
engineering coverage and configurable automatic numbering. See [BACKLOG.md](BACKLOG.md).
The Alpha/Beta preparation tools validate specific catalogue profiles; they
require the matching external inputs and a validated seed.

Current checks are recorded in [docs/VERIFICATION.md](docs/VERIFICATION.md).
Source-data handling is documented in [docs/SOURCE_AUDIT.md](docs/SOURCE_AUDIT.md).
